Security · Sep 2026

PressProof, media authenticity verifier

A desktop app that hides a signed fingerprint inside an image or WAV file, so a receiver can later check whether the file was changed. I owned the WAV audio engine.

  • Python
  • PySide6
  • cryptography
  • pytest
  • Implemented LSB steganography for 16-bit PCM WAV audio, embedding and extracting the packet at 1 to 8 least-significant bits per sample.
  • Integrated real signed packets (SHA-256 / RSA-PSS) into the WAV pipeline, with capacity checks that reject an oversized packet without writing output or touching the source file.
  • Wrote the WAV tests (round trips at every LSB count, capacity limits, malformed and non-PCM files, signature corruption); all 80 audio tests and 15 WAV end-to-end tests pass.

Team project for INF2005 Cyber Security Fundamentals (team of 6). The source code is private.

Embedded · Oct – Nov 2025

Line-following robot car

A Pico W robot car that follows a line, avoids obstacles and streams live telemetry to a web dashboard. I owned the IMU, which lets the car turn to an exact compass heading.

  • C
  • Pico W
  • I²C
  • MQTT
  • Wrote the I²C driver for the LSM303 IMU and computed compass heading from the magnetometer data.
  • Built turn-to-heading control with a configurable tolerance (5° by default) and a 10-second timeout that stops the motors if a turn stalls.
  • Calibrated the magnetometer for hard-iron and soft-iron distortion with a 360° rotation test. Turns that had landed 30–90° off target settled within the 5° tolerance.
  • Integrated the IMU with the team’s PID line-following, ultrasonic obstacle avoidance and MQTT telemetry to a live dashboard.

Team project for INF2004 Embedded Systems (team of 5). The source code is private.
